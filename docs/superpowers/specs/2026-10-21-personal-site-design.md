# Yisoul 个人主页设计

## 目标

用一套中文静态网站同时承载个人身份、科研/项目成果和长期写作，主要访客是技术同行与招聘方。首版使用 GitHub Pages 免费域名 `https://yisoul.github.io`。

## 信息架构

- 首页采用窄侧栏结构，左侧展示照片、姓名、身份和外部链接，右侧依次展示简介、News、精选项目与最近文章。
- 博客提供文章列表、文章详情、归档和按标签筛选。
- RSS、站点地图、404、Open Graph 元数据作为基础能力一并提供。
- 首版不包含评论、登录、数据库、站内全文搜索和内容后台。

## 视觉

- 接近 n+e 博客的极简编辑感：衬线标题、无衬线正文、窄内容栏、细分割线和大量留白。
- 浅色为默认主题，提供深色主题；颜色只用于少量标签与链接强调。
- 不依赖远程字体和 UI 组件库，使用系统字体保证中国大陆访问稳定。
- 细微滚动淡入在支持动效时启用，并尊重 `prefers-reduced-motion`。

## 技术实现

- Astro 生成纯静态 HTML，Markdown 文件承载文章。
- Markdown 的 frontmatter 保存标题、日期、描述和标签。
- 原生 CSS 与原生脚本实现布局、主题和轻量动效。
- GitHub Actions 在 `main` 分支推送后构建并部署 GitHub Pages。

## 验收

- `npm test` 通过。
- `npm run build` 通过。
- 首页、文章列表、文章详情、归档、标签、RSS、sitemap 和 404 均能生成。
- 在桌面与手机宽度下无横向溢出，导航与正文可读。
- 无 JavaScript 时正文仍可阅读，开启 JavaScript 时可切换主题。
